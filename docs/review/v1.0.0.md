## Review boundaries

Review the exact release above. EffectGate is a local Node.js 24 stdio MCP
runtime, not an operating-system sandbox. Its reviewed third-party backend
surface is read-only and digest-pinned. Redaction and opacity detection are
bounded heuristics. Streamable HTTP, unreviewed executables, and third-party
writes are outside v1.0.0.

Native installers are a QA addendum, not a different runtime build. Packaging
commit `f17ff82` downloads and verifies the exact tarball above before wrapping
it in four unsigned platform packages. Review both the runtime identity and the
packaging boundary; do not attribute post-release runtime changes to v1.0.0.

These installers are not code-signed or notarized. Platform trust warnings are
expected and must be reported separately from package-integrity failures.

Security review should cover:

- JSONL framing, request identity, lifecycle, timeout, and backpressure bounds;
- executable, argv, working-directory, source, identity, and catalog pinning;
- environment-only secret references and error/output sanitization;
- CAS partitioning, finalization, quarantine, cursors, paging, and invalidation;
- redaction, opaque-content withholding, search, and structured projections;
- phase/Capsule/policy binding, approval leases, idempotency, verification,
  reconciliation, receipts, backup, restore, rollback, purge, and uninstall;
- package contents, checksums, SBOM, provenance, and release signatures.

QA review should cover:

- installation and removal of MSI, PKG, DEB, and RPM packages with Node.js 24;
- CLI version, fixture startup, MCP initialization, discovery, and tool calls;
- reviewed stdio configuration acceptance and fail-closed drift handling;
- large-result paging, search, projection, redaction, and unavailable views;
- protected-effect approval, denial, restart, recovery, and manual resolution;
- external-state preservation across reinstall, upgrade, rollback, and removal;
- documentation accuracy and reproducibility of reported release evidence.

## Reproduce the released package

```text
git clone https://github.com/Miniks040506/EffectGate.git
cd EffectGate
git checkout v1.0.0
git rev-parse HEAD
npm --prefix poc test
```

Download `effectgate-preview-1.0.0.tgz` from the release and verify its digest
before installing it. Do not use maintainer-provided credentials, private
keys, state databases, or unpublished evidence.

For native QA, download the installer and its matching `SHA256SUMS-*.txt`,
verify the digest above, and follow the commands in
[`docs/native-installers.md`](../native-installers.md). Record any platform
warning, installation side effect, and uninstall residue in the report.

## Required reviewer report

The independent report must include:

1. reviewer name or organization and any conflict of interest;
2. review date, environment, runtime and packaging commits, package digests,
   and evidence used;
3. methods and areas reviewed, including anything omitted;
4. findings with severity, reproduction steps, impact, and remediation advice;
5. QA platform results and unresolved compatibility gaps;
6. a final `pass`, `conditional_pass`, or `fail` verdict.

Report vulnerabilities privately through the process in
[`SECURITY.md`](../../SECURITY.md). Non-sensitive QA findings may use GitHub
Issues. EffectGate must continue to describe the release as independently
unreviewed until a report satisfying this section is received and linked.
